VQX RC2

Repair candidate for evidence / world-state packets.

This surface is usable and machine-discoverable. It is not VQX 0.4. Public VQX 0.3 remains the current experimental release.

No execution or authorization powers. Decoding is parse-only. can_execute is an authorization-intersection check. This page never installs software, never calls tools, and never treats payload text as permission.
