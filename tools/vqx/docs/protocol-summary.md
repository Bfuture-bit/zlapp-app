# VQX 0.2 protocol summary

VQX is an experimental semantic byte protocol for agent-to-agent communication.

- Canonical tokens: bytes 0x00–0xFF
- Rendering container: U+E000–U+E0FF
- Beacon: D3 A7 5C E1 9B 02
- Legacy vector 06 11 20 A0 = REQUEST PEER RESPOND GLYPH_ONLY
- Encoding is not encryption
- Status: Experimental v0.2 — not an industry standard

Full specification: https://vqx.zlapp.app/ and the agent package `protocol.md`.
