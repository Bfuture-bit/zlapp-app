# VQX human dictionary v0.2

Human-facing dictionary for auditing, debugging, and implementation.

Canonical host: https://vqx.zlapp.app/

Human-language names are **not** part of compact VQX payloads. The wire format is unsigned bytes `0x00`–`0xFF`. This package exists so people and tools can inspect the mapping.

Open `dictionary.html` in a browser (custom font included). CSV and JSON contain the same 256 entries.

Beacon: `D3 A7 5C E1 9B 02` = `U+E0D3 U+E0A7 U+E05C U+E0E1 U+E09B U+E002`.
