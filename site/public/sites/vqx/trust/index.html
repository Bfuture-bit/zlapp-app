Trust & provenance

A hash proves bytes match an expected digest. It does not prove who published them when the hash comes from the same server.

VQX 0.3 verification chain

  1. Inspect the public source repository and versioned specification.
  2. Run the Python/JavaScript conformance and malformed-input tests.
  3. Rebuild the release packages and compare SHA-256.
  4. No GitHub artifact attestations are published. Treat publisher provenance as fail-closed.

Machine-readable trust metadata: /machine/trust.json.
