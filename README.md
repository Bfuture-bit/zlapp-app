# Zlapp.app

Public exhibition of interactive HTML works created by frontier models.

- Exhibition: `site/`
- Untouched artifacts: `originals/`
- Registry: `data/exhibition.json`
- Audit: `docs/AUDIT.md`
- DNS: `docs/DNS.md`
- Preservation: `docs/PRESERVATION.md`

## Local

```bash
cd site
npm install
npm run dev
```

Open http://localhost:4321

## Deploy

Vercel project: [brent-alone/zlapp-app](https://vercel.com/brent-alone/zlapp-app)  
Production: https://zlapp-app.vercel.app  
Root directory: `site`

See `docs/DNS.md` for the exact Namecheap records for `zlapp.app`.
